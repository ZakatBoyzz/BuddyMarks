КАК ПОЛУЧИТЬ JAR ЧЕРЕЗ GITHUB

1. Распакуй этот архив на компьютере.
2. Открой github.com и войди в аккаунт.
3. Нажми + -> New repository, придумай имя, выбери Public или Private и создай репозиторий.
4. В репозитории нажми Add file -> Upload files.
5. Загрузи ВСЁ СОДЕРЖИМОЕ этой папки (включая папку .github; если она скрыта, включи показ скрытых файлов). Не загружай архив ZIP как один файл.
6. Нажми Commit changes.
7. Открой вкладку Actions. Workflow «Build BuddyMarks (Minecraft 1.21.4)» должен запуститься автоматически. Если GitHub попросит разрешить Actions, разреши.
8. Когда запуск завершится зелёной галочкой, открой его и найди раздел Artifacts. Скачай «BuddyMarks-Minecraft-1.21.4» — это ZIP с JAR-файлом.
9. Распакуй скачанный artifact ZIP. Файл .jar положи в папку mods клиента Fabric 1.21.4.

ВАЖНО:
- Этот архив настроен на автоматическую попытку сборки, но компиляция ещё не была подтверждена успешным запуском. Если Actions завершится красным крестиком, открой лог Build the mod и пришли сюда текст ошибки/скриншот.
- Успешная сборка JAR сама по себе не доказывает, что все функции мода протестированы и работают без ошибок.
- Для сетевой синхронизации меток серверная часть должна быть установлена на сервере; один только клиентский JAR не добавляет мод на сервер.
